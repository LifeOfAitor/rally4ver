# CLAUDE.md

## Project: Rally4ver

Cross-platform (iOS + Android) app that reads **rally pacenotes** aloud while you drive a pre-defined route, like a rally co-driver. It runs in the background next to Google Maps / Waze. Built with **React Native + Expo (SDK 58) + TypeScript**, same stack as RadarMoto (`~/source/app_radares`), from which config and patterns are copied. Distributed for free as an APK on GitHub (iOS build too).

UI language: Spanish. Use at the user's own responsibility; always show a safety disclaimer before a stage.

## Commands

```bash
npm test                 # Jest unit tests (pure logic in src/core)
npm run typecheck        # tsc --noEmit
npx expo install <pkg>   # ALWAYS use instead of npm install — picks SDK-compatible versions
npm run android / ios    # dev client build (Expo Go does not work: background location, MapLibre)
```

Run `npm test` and `npm run typecheck` before declaring work done. Build/test instructions for release builds and simulated drives: see RadarMoto's CLAUDE.md (same tooling).

## Architecture

```
route (LatLon[]) → buildPath (resample every 5 m, local XY)
  → generatePacenotes (curvature → bends → grade 1-6 + modifiers + links)
  → while driving: GPS fix → matcher (s along route) → caller (notes due at speed) → audio
                                                    → timer (live delta vs best run)
```

## Pacenote rules (keep these when changing code)

- **Scale 1-6: 1 = tightest, 6 = almost flat.** Grade by minimum radius: <20, <35, <55, <85, <130, <200 m. Wider is not called.
- Grade uses the **racing-line radius** `R + lane / (1 − cos(θ/2))` (lane 2.5 m), so short bends grade faster than long ones of the same radius; line radius > 250 m is flat out and not called.
- Hairpin (`horquilla`) = ≥140° total and radius <25 m.
- Bends turning <20° in total are ignored; same-direction bends <10 m apart are merged.
- Gap <25 m → `y`; otherwise rounded to 30/50/70/100/150/200/250/300, then 100s; >1 km → "larga recta".
- `cuidado` before grade ≤2 or hairpin after ≥250 m of straight.
- Spoken order: `[cuidado] dirección grado|horquilla [larga] [cierra|abre] [y|distancia]`.

## Simulated drive (iOS simulator)

Fetch a route's coordinates and feed them as GPS: `xcrun simctl location <udid> start --speed=25 --interval=1 lat,lon lat,lon …`. Speech activity shows in `log show --predicate 'process == "Rally4ver" AND eventMessage CONTAINS "_speechJobFinished"'`. The simulator may stop delivering fixes ~100 m before the last waypoint; `location set` the end point to finish.

## Releases (Android APK on GitHub)

```bash
npx expo prebuild --platform android
cd android && JAVA_HOME=/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home ./gradlew assembleRelease -PreactNativeArchitectures=arm64-v8a
gh release create vX.Y.Z rally4ver-android-vX.Y.Z.apk --title "Rally4ver X.Y.Z (Android)" --prerelease
```

arm64-only keeps the APK ~38 MB (all ABIs: ~120 MB). Bump `version` in app.json. Signed with the template debug key (fine for sideloading; a real keystore is needed before Play Store, and updates must keep the same key). Repo: github.com/LifeOfAitor/rally4ver.

## Personal iPhone install (free Apple account)

```bash
npx expo prebuild --platform ios --clean
cd ios && xcodebuild -workspace Rally4ver.xcworkspace -scheme Rally4ver -configuration Release -destination id=<iPhone UDID> -derivedDataPath build/device -allowProvisioningUpdates DEVELOPMENT_TEAM=Z9CW88PP6L CODE_SIGN_STYLE=Automatic build
xcrun devicectl device install app --device <UDID> build/device/Build/Products/Release-iphoneos/Rally4ver.app
```

`xcrun devicectl list devices` gives the UDID. Free (Personal Team) signing expires after 7 days: rebuild and reinstall; data is kept. Free teams can't sign Push Notifications, so never add `expo-notifications` (or another plugin that adds `aps-environment`). First install: Settings → General → VPN & Device Management → trust.

## Voice

Voices offered in AJUSTES are listed in `scripts/voices.json` (id, label, Piper model, speaker); clips go to `assets/voice/<id>/` and `clips.ts` exports `VOICES` + `DEFAULT_VOICE` (the second entry). Regenerate after changing the vocabulary or the voices (Piper needs Python 3.9–3.13 and ffmpeg):

```bash
python scripts/generate_voice.py --models-dir <dir with Piper .onnx voices> [--length-scale 0.85] [--espeak-data <copy of piper/espeak-ng-data>]
```

`vocabulary.test.ts` fails if the pacenote engine can say a token without a clip. Voices: rhasspy/piper-voices (check each MODEL_CARD license and credit it in AJUSTES). `muestras-voz/` holds listening samples and is gitignored.

## Gotchas

- expo-audio SDK 58: `AudioPlaylist.add()` does not resolve `require()` asset ids (the constructor does) — `voice.ts` resolves them with `Asset.fromModule`. Without that the playlist silently never plays.
- If `--espeak-data` is the bundled folder named `espeak-ng-data`, Piper ignores it; copy it to a folder with another name.

- The map takes a few seconds to appear in the iOS simulator (black until tiles load) — not a bug.
- Don't read the clipboard automatically on iOS: it shows a "paste" permission prompt every time. Android only.
- npm 11 skips some install scripts (`npm install-scripts ls`); harmless so far for tests and the iOS build.

## Product decisions

- **Finding the twisty road**: OSRM's own alternatives stick to the fast roads (with A/B marked by hand the mountain road over Jaizkibel never came up). With 2 stops the editor also runs `findMoreRoutes` (data/routing.ts + core/alternatives.ts): route through points ±12 % of |AB| to each side at 1/3, 1/2, 2/3; drop the out-and-back detour; route again through the point farthest from known routes; reject retraces, >2.5× time / >2× distance, and duplicates (overlap ≥ 0.85). ~9 requests, sequential, a few seconds; routes are appended as found. Chips show curves and MÁS RÁPIDA / MÁS CURVAS. A reopened stage whose saved road isn't found again is offered as «Tu ruta guardada».
- **The user picks the road** ("la ruta a la que darle caña"), not the router. Google links carry only stops (plus `!5i<n>` = chosen alternative), so: show OSRM alternatives (only with 2 stops) and preselect `!5i`; a map tap adds a via in the leg it belongs to (`core/stops.ts`); after reversing or moving stops keep the most similar route (`core/routeMatch.ts`). Reverse button swaps start/finish.
- Always a fixed route (no free / predictive mode). Routes from: A→B on the map, Google Maps share link (origin/destination/waypoints re-routed on OSM, then drag to adjust), GPX import.
- Recce mode (record a drive, notes from the real GPS trace) and stage timer with live delta vs best run (optional, off by default) come after the MVP.
- Voice: pre-generated AI clips per token (Piper / ElevenLabs). Never ship copyrighted samples from games or videos.
